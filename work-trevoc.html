Case Study 01

Trevoc

Ultra-luxury high-rise, Sector 56, Gurugram Digital / Motion / Social 2024

The Brief

590 assets across the engagement

Client — Trevoc, Gurugram · Role — Graphic Designer · 2024

One brand, one identity, every week — without it ever feeling rushed.

Project goal

Continuous digital presence for an ultra-luxury launch: celebrity brand-ambassador work, a daily SVS grid, investor EDMs, and internal HR comms — all reading as one coherent brand.

Design decision

A modular system built for velocity rather than a single hero campaign — fixed type and negative space, imagery and format doing the differentiation week to week.

Inspiration

Reference & direction

Reference points for Trevoc, in place of a scanned moodboard — swap for the actual reference set: OTT/streaming title-card aesthetics for the "Retiring" teaser series, celebrity-endorsement print campaigns for tone, and luxury real estate grid design (Sotheby's / Trump-tier developer marketing) for restraint and material confidence.

Approach

Design decisions
01

A repeatable grid, not a repeated layout

Built a modular composition system so 9-tile SVS grids could vary week to week while staying recognisably Trevoc — type position and negative space held constant, imagery rotated.

02

Type as the brand anchor

With imagery changing constantly, a fixed typographic system — one display face, tight tracking, gold foil-adjacent accent — carried brand recognition across every touchpoint.

03

Design for the format first

Every key visual was built with its 1:1, 9:16, and 16:9 crops considered from the first draft, not adapted afterward — visible in the System section below.
